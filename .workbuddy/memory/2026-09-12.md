# 2026-09-12

## ObsidianMind UI 从 0 到 1（第一版产品级 UI 完成）

- 全新项目，技术栈：Vue 3.5 + TS strict + Vite 6 + Pinia + Vue Router(hash) + lucide-vue-next + marked；样式用 CSS Design Tokens（tokens.css，禁 hex 硬编码），无 Tailwind。
- 结构：src/{types,services(mock),stores,router,components/{layout,knowledge,ai},views}；5 个 service 全部 Mock 化（knowledge/search/ai/index/settings），UI 与数据层解耦，未来直换 REST/SSE。
- 页面：Home（知识驾驶舱）/ Note（read/edit + markdown）/ Graph（自研力导向 SVG，拖拽/缩放/平移/点选详情面板）/ Search（AI Search + 分词停用词匹配）/ Settings（7 分区）/ AiFocus（Ask your Knowledge 六场景）。三栏 Shell + Header 本地状态弹层 + StatusBar Local First。
- Mock 亮点：21 篇真实感笔记（Java/AI/个人成长/项目/自媒体）、6 组关键词路由的 AI 预置回答（带 sources/relatedNotes）、聊天二阶段 thinking（检索→生成）。
- 踩坑记录：
  1. **SVG 图谱节点点击"失效"**——根因是 1200×800 世界坐标超出可视区（节点在视口外），挂载时必须 fitToView（k=min(vw/W,vh/H)*0.9 居中），不是事件绑定问题。
  2. 搜索多词中文查询曾因"全部关键词需命中"返回空 → 分词 + 停用词过滤 + 任一概念词命中即计分。
  3. agent-browser 调试技巧：元素在视口外时 Playwright click 假成功；用 elementFromPoint + __vueParentComponent.setupState 定位是渲染问题还是事件问题。
- 验证：vue-tsc strict 0 错误，vite build 0 警告（207KB js / gzip 77KB），dev :5199 浏览器全链路截图验证（首页→笔记→AI 问答→Sources 跳转→图谱→搜索→设置）。
- 运行：`npm run dev`；构建 `npm run build`。
